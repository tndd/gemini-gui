# Gemini GUI ターミナルセッション仕様書

## 概要

本ドキュメントは、gemini-guiにおけるターミナルセッション管理の現状と目標仕様を定義し、独立した疑似ターミナルによるコンテキスト管理の実装指針を示すものです。

## 現状仕様

### アーキテクチャ概要

現在のgemini-guiは、以下の2つのAPIエンドポイントで異なるアプローチを採用しています：

1. **新方式** (`/api/messages`)：セッション別プロセス再利用
2. **旧方式** (`/api/terminal`)：毎回新プロセス生成

### 現状の実装詳細

#### プロセス管理
- **プロセス生成**：`spawn('gemini', ['--model', 'gemini-2.5-flash'])`
- **管理方式**：`Map<string, ChildProcess>`によるセッション別管理
- **ライフサイクル**：セッション開始時に生成、終了時に削除

#### 状態管理
- **データベース**：SQLiteでセッション情報を永続化
- **メモリ**：アクティブセッションIDを`activeSession.ts`で管理
- **ワーキングディレクトリ**：セッション作成時にデータベースに保存

#### コンテキスト管理
- **制限**：過去10件のメッセージのみ保持
- **実装**：データベースから取得したメッセージ履歴をプロンプトに含める
- **フォーマット**：テキストベースの会話履歴構築

### 現状の問題点

#### 機能面の制限
1. **対話的コマンド未対応**：非対話的コマンドのみ実行可能
2. **リアルタイム出力なし**：プロセス完了まで応答待機
3. **長時間実行制限**：30秒タイムアウトで強制終了
4. **コンテキスト制限**：10件の固定制限

#### 技術的課題
1. **二重実装**：異なるAPIエンドポイントの併存
2. **プロセス監視不足**：生存チェックが不十分
3. **リソース管理**：メモリリークの可能性
4. **エラー処理**：不完全な例外処理

#### パフォーマンス課題
1. **プロセス起動コスト**：旧方式での毎回新プロセス生成
2. **メモリ使用量**：セッション数制限なし
3. **同時実行制限**：セッション内逐次実行のみ

## 目標仕様

### 基本コンセプト

**セッション内独立疑似ターミナル**：各セッションが独立したPTY（疑似端末）を持ち、真のターミナル環境でのコンテキスト継続を実現する。

### アーキテクチャ設計

#### 疑似ターミナル管理
```typescript
interface SessionTerminal {
  sessionId: string;
  pty: IPty;
  workingDirectory: string;
  environment: Record<string, string>;
  createdAt: Date;
  lastActivity: Date;
  isActive: boolean;
}
```

#### セッション管理
- **1セッション = 1PTY**：セッションごとに独立したPTYプロセス
- **永続化**：セッション削除まで継続
- **状態保持**：環境変数、ワーキングディレクトリ、コマンド履歴を保持

### 機能要件

#### 対話的コマンド対応
- **リアルタイム入出力**：WebSocketによるストリーミング通信
- **プロンプト処理**：対話的な入力プロンプトへの対応
- **制御文字**：Ctrl+C、Ctrl+Dなどの制御文字サポート

#### 長時間実行プロセス
- **バックグラウンド実行**：長時間実行タスクの継続
- **プロセス管理**：実行中プロセスの状態監視
- **中断・再開**：プロセスの中断と再開機能

#### コンテキスト継続
- **環境変数継承**：セッション内での環境変数変更の継続
- **ワーキングディレクトリ**：cdコマンドでの移動の継続
- **コマンド履歴**：bashのhistory機能活用

### 技術実装

#### PTYライブラリ
```typescript
import { spawn } from 'node-pty';

// セッション用PTY生成
const pty = spawn('bash', [], {
  name: 'xterm-color',
  cols: 80,
  rows: 24,
  cwd: workingDirectory,
  env: sessionEnvironment
});
```

#### WebSocket通信
```typescript
// リアルタイム通信
interface TerminalMessage {
  type: 'input' | 'output' | 'error' | 'exit';
  sessionId: string;
  data: string;
  timestamp: Date;
}
```

#### セッション管理API
```typescript
// セッション管理エンドポイント
POST   /api/sessions              // セッション作成
GET    /api/sessions              // セッション一覧
GET    /api/sessions/:id          // セッション詳細
PATCH  /api/sessions/:id          // セッション更新
DELETE /api/sessions/:id          // セッション削除
WS     /api/sessions/:id/terminal // ターミナル通信
```
